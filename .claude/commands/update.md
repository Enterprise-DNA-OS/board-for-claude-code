# /update

Read the full record first. Show the proposed field changes, use the operator's instruction as authority, and keep historical interests by closing them.

```bash
node scripts/board.mjs show <kind> "<name or id>"
node scripts/board.mjs update <kind> "<name or id>" --field=value
```

Use the configured database. Add `--json` to board.mjs calls when structured output helps. If a name is ambiguous, list the candidates and ask. Never guess a record or send a message.
