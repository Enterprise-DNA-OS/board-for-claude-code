# /board-pack

Render the meeting pack with its agenda, paper summaries, archive references, actions and interests. This does not merge original PDFs.

```bash
npm run docs -- board-pack <meeting-id-prefix>
```

Use the configured database. Add `--json` to board.mjs calls when structured output helps. If a name is ambiguous, list the candidates and ask. Never guess a record or send a message.
